# 翻滚直接伸腿接起身（2026-10-23）

用户确认试用：1.6秒翻滚结束后直接0.2秒伸腿，然后立即起身。取消旧版重新收腿、躺倒姿态等待及展开后0.2秒保持。这里翻滚结束指有效运行计时到1.6秒，不声称检测到物理完整一圈。

上一版实机记录在1.6秒重播0.1秒整套actor目标，使#30目标约−90→+70°、#31转至+90°，到2.18秒才交起身。新版从上一帧已经编码限位后的实际下发角度减去HOME得到展开起点；10个50Hz控制目标线性将双腿偏移归零，表示现有HOME参考腿角，不是机械极限。头颈保持最后下发目标，不重播旧收腿头目标。
