# 轮滑转向输入筛选（2026-10-29）

结论：在现役539e6b2e模型上，推荐把“前后回中时的原地转向”设为固定有效档：目标航向变化率±0.9rad/s，松杆归零；滑行转弯保留原±0.5rad/s。模型接收的航向误差仍夹紧±0.5rad，不能把模型第三维直接写成0.9。0.9是目标航向随时间变化的速度，实际转速更低。

本轮用户明确先不部署。没有修改运行控制代码、模型权重或设备参数；提供参数候选和仿真证据。低非零推力叠加转向仍有不稳定区，尚未验证一套覆盖整个连续摇杆平面的平滑映射，不能称全部手柄位置已解决。

## 推荐输入

| 模式 | 推力 | 转向意图 | 航向变化率 | 模型误差限幅 |
|---|---:|---:|---:|---:|
| 原地左/右转 | 0 | ±0.25有效档 | ±0.9rad/s | ±0.5rad |
| 前进/倒滑转 | ±0.4 | ±0.25 | ±0.5rad/s | ±0.5rad |
| 松杆 | 0 | 0 | 0，锁当前航向 | 保留原航向纠偏 |

原地满转意图换算倍率从2变为3.6。不能只把全局线性倍率改为3.6：半杆/小杆会重新落入低变化率弱响应区。建议前后摇杆回中时按左右方向选择固定有效转向档，转角通过按住时长控制；这会牺牲原地转向的小杆慢转细腻度。滑行档不随此次原地参数一起加快。此映射建议尚未接入运行代码。

## 排除方案与局限

- 把模型误差上限缩为0.2/0.3/0.4rad没有解决右转，部分接近静止。
- 起始航向额外偏置0.2/0.35/0.5rad不稳定，不采用。
