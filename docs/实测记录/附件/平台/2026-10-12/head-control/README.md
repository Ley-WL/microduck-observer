# 2026-10-12 头部轮盘与三栏遥控

范围：App 左侧行走、中间技能（倒地起身/动态坐站/拾取/翻滚/停止保持）、右侧头部轮盘，嘎一下位于其下。主板增加 BLE command 的 headPitch/headYaw，范围[-1,1]，旧 App 缺省0；状态增加 headControl/headReady。

头部只在当前BLE会话自己的 kissqy 同步行走模型就绪时开放，身体技能和反馈暂停时不接受偏转。左右输入为head yaw，抬头输入反向映射机械head pitch；在现有模型目标上附加俯仰±25°、偏航±35°，已有机械角度/编码/EEPROM边界继续校验。唯一UART owner的50Hz周期按每帧至多1.2°改变偏转量；松手回0偏转，即渐回模型姿态，不是归零标定或强制HOME。两轴输入独立于行走速度。超过250ms没有刷新自动回0；切后台、断连、急停、停止、技能切换和反馈暂停清输入。没有增加舵机使能入口、改变PD、权重或原始动作历史。
