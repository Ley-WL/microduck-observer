## 后续记录方式

1. 新实測追加到对应主题，注明日期、设备、条件、操作、结果与未验证项，并更新本页状态。
2. 区分“工具直接实测”“用户反馈”“推测”；成功、失败都保留，不用后来的结果改写历史。
3. 记录配置变更、备份和回退位置；不记录密码、绑定码等凭据。
4. 抓帧和日志等证据放在本目录附件中，注明来源。照片清晰、设备识别成功或数据出包，都不等于完整硬件功能验证。
5. 历史归档只追溯；旧入口文件只跳转，避免多处维护不同版本。
