## 接线表（2026-09-29 补录）

以下为本次聊天给出的接线方案，针脚号均为 Radxa ZERO 3W 的物理编号。工具已实测确认模块在 I²C4、0x29 工作；尚未通过实物照片或逐线导通确认全部接法，不能将方案直接当作实物接线验收。

| ToF 模块引脚 | 主控接线方案 | 验证边界 |
|---|---|---|
| VIN | Pin 17，3.3V | 原建议以模块支持3.3V输入为前提；实际供电取自哪个脚、实际电压未确认 |
| GND | Pin 14，GND | 原建议接法；实际使用的地脚未确认，必须与主控共地 |
| SDA | Pin 27，I²C4 SDA M0 | 已确认I²C4通信成功，实物逐线未拍照核对 |
| SCL | Pin 28，I²C4 SCL M0 | 已确认I²C4通信成功，实物逐线未拍照核对 |
| INT | 轮询读取时可不接 | 实际是否接线未确认 |
| LPn | 需保持有效高电平；板载有合适上拉才可不接 | 实际接法及板载上拉未确认；不能凭已出帧认定悬空可用，不接5V |

方向沿用主板已纠正记录：芯片面朝上、排针在左、USB在右、天线在下，从下往上数；靠芯片的内排为奇数，靠板边的外排为偶数。Pin 17为内排第9个，Pin 14为外排第7个，Pin 27/28分别为内/外排第14个。线色未记录，接线前须断电。

软件对应 `/dev/i2c-4`、7位地址 `0x29`，tofd通过 `--bus /dev/i2c-4` 读取。实测与配置变更见下文。
