## 接线与设计依据

本节为PCB/原理图与照片核对，不能替代逐线导通、电压和贴装验收。

| 接口/元件 | 核对结果 | 验证边界 |
|---|---|---|
| J13 / J14 | JST EH 2.5mm三针；1=GND，2=+BATT，3=DATA；两口同一TTL总线 | 外部电源由1/2脚输入，一个口供电、另一个接舵机；舵机正极为电池原压，不是5V |
| J4 | 主板40Pin；2/4=5V，6=GND | 已通过该路径启动主板；其余脚并非全部空脚 |
| J2 / J9 | 外接麦克风双孔端子，1=GND，2接音频输入电路 | 不能输入电池电压 |
| J3 / J11 | 四针RS485舵机接口 | 不能直接套用三线TTL接法 |
| R33 | 150Ω，0402，串在TTL DATA路径中 | 用户已短接；焊点/最终阻值未独立测量 |
| TH1 | BOM标称100Ω thermistor，串在DATA到连接器路径中 | 短接R33并未移除TH1；实际阻值未测 |
| R32 | 10kΩ，0402，将收发公共节点上拉至3.3V | 不应当作R33短接；未记录用户修改它 |

信号路径：`U7发送/U6接收公共节点 ↔ R33 ↔ TH1 ↔ J13/J14 DATA`；R33与TH1之间另接D4对地钳位。Q1控制收发方向；U5将TTL接收和U8的RS485接收输出做AND后送主控RX。此结构提示收发切换及RS485支路也可能影响TTL接收，但未做波形定位。

照片方向严格区分：

- 正面竖放、40Pin在左、麦克风在上时，底部两个三针口从左到右为 **DATA / +BATT / GND**。
- 背面横放、黑色40Pin插座在下、舵机接口焊点在左时：上排从左为1/3/5…，下排从左为2/4/6…；下排前两孔5V、第三孔GND。
- 不把上述左右关系套到翻面或旋转后的板子，不凭线色判断。飞特现有2.0mm线束与HAT 2.5mm接口需要针序匹配的转接线；旧USB转接板不能同时驱动同一DATA。

官方[README](https://github.com/pollen-robotics/elec_RPI_Robot_HAT)明确通过舵机连接器输入电源。当前工程引用`power.kicad_sch`、`audio.kicad_sch`、`sensors.kicad_sch`和`dynamixel.kicad_sch`；仓库另存的`pwr_supply_charge.kicad_sch`不在此层级中，其J9为USB-C，不能套用于本实物。

### 5V电源设计核对（2026-09-30，非实测）

`+BATT → U9 AP63205 → L4 → Q2/LM5050-1 → +5V → J4 Pin2/4`。AP63205为固定5V、2A级，不是3A；LM5050-1供电来自最终5V，处于其保证范围下沿，启动/动态余量仍需波形验证。输入为降压而非升降压；HAT标称输入范围不能作为现有低压舵机的允许电压。输入防反接、双电源行为及完整PCB热/载流能力没有验收。

### 传感器扩展口（设计方案，尚未迁移实测）

- J5：1GND/2=3.3V/3SDA/4SCL，对应主控物理3/5，在当前Radxa配置为I²C3。
- J6：默认R18/R19为0Ω，信号到物理7/29；不是当前ToF的27/28。改接27/28需移除原桥接、改R17/R16，尚未执行。
- J7：1GND/2=3.3V/3→物理24 RX/4→物理21 TX，可研究UART9-M1接MS901M；尚未配置或实测。
- 现有IMU UART4及ToF I²C4的历史接法仍见[主板与接线](01-主板与接线.md)，不能声称已经迁到HAT扩展口。

### 对乱码的核对

- `stty`确认1Mbps、8N1、无软硬件流控；Linux无串口console，相关getty inactive。
- 对失败原始字节逐偏移查找，不限定舵机ID和37字节长度，仍未找到任何完整校验正确的协议帧。先前成功同步回包为555字节（15×37），同协议曾正常工作。
- UART的`fe`是帧格式错误，`brk`是BREAK；应用统计的`checksumErrors=0`不代表无错误，因为乱码可能根本未进入完整帧校验。
- 低频单颗查询同样失败，不足以归因“50Hz太快”或“同步读取碰撞”。没有示波器证据，未排除电源瞬变、焊点、线缆、方向切换或实际位宽异常。
- 用户后报约4.87V，但未最终确认测点/带载条件；不能据此认定欠压，也不能排除瞬时跌落。

## 2026-10-02 板载BMI088首次读取（工具实测）

用户要求检查HAT板载IMU。依据C1 BOM，U11为BMI088，SDA/SCL接主控物理3/5，当前映射/dev/i2c-3（i2c-pihat）；R14将SDO1上拉，定向读取0x19寄存器0x00返回0x1E（加速度计），0x68返回0x0F（陀螺仪），0x69无应答。总线上0x18是已绑定tlv320aic3x的音频设备，本次未访问或强制占用该地址。
