# 轮滑 X 蹲滑（代码已接入，尚未部署）

2026-10-25。按用户确认的官方单次动作路线实现，使用 HD1910 自训1001更新模型（完整训练跑到8000更新后择优）。

| 当前状态 / 按键 | 行为 |
|---|---|
| 卸力 / 轮滑安装姿势 | X不启动蹲滑；先装轮并按A进入轮滑平衡 |
| 轮滑平衡中按一次X | 切换独立蹲滑模型，可以在左摇杆仍有输入或惯性滑行时触发 |
| 动作阶段 | 0.5有效秒下降、2秒低位、0.5秒站起，再保持站姿0.5秒；无需按A |
| 第3.5有效秒 | 官方5秒相位周期到0.7，自动交回原轮滑模型的零输入平衡 |
| 蹲滑中重复X / 按A | 不重启计时、不提前跳过站起；A无需承担起身功能 |
| B / Back | 原停止保持 / 全卸力优先，停止后不会自动恢复 |

相位在唯一UART owner的50Hz native循环中使用 `[cos(2πφ),sin(2πφ),0]`，发送目标后推进；反馈暂停时不虚增动作时间。进入与返回不HOME、不重新使能，不修改实物速度/动量；相同HOME和原始action历史沿现有模型交接路径保留。回轮滑后沿原手柄回中再授权方向输入的规则。

蹲滑为独立的全身模型，执行期间不叠加右摇杆头控或身体推力；正常轮滑和安装保持的鸭叫、头控不变。嘴部/叫声仍沿现有串口和音频路径，停止/卸力随时优先。网页与实体手柄均将轮滑模式X覆盖为“蹲滑（自动站起）”，普通模式的用户绑定不改写。

模型单独注册在 `roller_crouch` 槽，文件 `models/roller_crouch_hd1910_1001.onnx`，SHA `dd2530b07591d825f1ef88b0c9f19e93779d2557591958995a14b9c8133d1453`。旧注册表只在内存增补缺失槽，保留已有选择/回退/版本号；原轮滑模型不替换。缺模型时X不可用。模型在启用前与轮滑actor一起预加载、预热，切换期间不加载网络。
