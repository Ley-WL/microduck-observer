# 背朝下姿态结束翻滚，0.5秒伸腿后起身

2026-10-23 用户明确：不要求完整一圈，背部着地时结束翻滚，伸直0.5秒再起身。现有系统无背部接触传感器，因此实现为背朝下姿态近似，不能宣称检测到落地。

坐标依据：既有 getup CPU 评估定义 supine 为 pitch −π/2；运行器以机身旋转矩阵转置乘世界重力，仰躺时 projected gravity 指向 −X。新版先见过直立（与竖直偏差<30°），然后在至少0.2有效秒后连续两次观测满足归一化 −gx≥cos25°，确认首次接近仰躺；不将趴卧+X、侧卧±Y或倒立+Z混为背部朝下，不累计完整旋转圈数。

实机最近两次记录在约0.8秒到背朝下时仍有6～7rad/s角速度，若强制等<4rad/s会错过姿态并继续翻。因此此版不加低角速度等待；姿态确认后停止继续推理翻滚actor，从最后实际下发角度开始，以25个50Hz目标/0.5秒线性展开双腿到既有HOME参考角，再接起身。停止输出翻滚动作不保证身体惯性立即消失。头颈保持末目标，切起身仍用0.3秒过渡，不回放早期收腿目标。
