# 统一技能切入行走（2026-10-22）

用户要求统一模型切换策略，尤其其他动作进入行走。

## 共用规则

`walk_handoff::Gate` 是唯一的行走交接姿态门：倾角<10°、角速度模<0.5rad/s、10个腿关节各自HOME偏差<0.30rad、各自速度<1rad/s，连续有效观测至少500ms。间隔>60ms、无效观测、模型切换清空证书。当前样本不合格立即清零，不能凭前一帧已站稳放行。

Native50与Worker100两条路径以及手动返回行走，都调用相同的路由器。旧的动作时长仅决定动作阶段结束，不再直接允许进入行走。

| 当前状态 | 收尾策略 |
|---|---|
| 坐姿 | 先切坐站的站起，再经过共用门 |
| 单脚保持 | 先落脚，再经过共用门 |
| 翻滚 | 保留1.6秒翻滚→收腿→IMU躺倒门→起身；不接受中途直接跳行走 |
| 拾取、左右踢球、舞蹈、落脚动作结束 | 已站稳直接行走；未站稳由倒地起身actor从当前姿态接管，不增加躺倒动作 |
| 起身、站起 | 达到共用500ms门立即行走，没有额外3秒/6秒最低等待；10秒仍未满足则卸力 |

非行走目标、HOME出口的现有语义保持。模型权重、增益、限位、急停和行走/舞蹈倾倒保护不变。旧getup元数据中的3秒/1秒仅保留为原artifact校验信息，不能用来判断新版实际行走交接条件。

遥测：`walkHandoffRevision=shared-standing-500ms-v1`，`walkHandoffStableSeconds`、`walkHandoffReady`。transition日志保存交接前的稳定时长，便于实测确认。
