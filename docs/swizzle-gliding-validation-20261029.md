## 关键发现

1. 网格1536次全部未触发倾倒门，但108次保持10秒转角不足10°，439次不足目标航向积分的一半。半积分指标用于诊断响应不足，不是训练合同中的硬验收线。
2. 满前后推力±0.4的384次静态网格，左右小/半/满杆均无反向且无低于半积分样本。满转向10秒约269.7～291.5°。这不排除启动初态风险。
3. 前进推力0.1、满右转32次，平均38.7°、最小6.4°，29次不足目标积分的一半；相同推力满左转平均213.9°。低速左右明显不对称。
4. 动态256次有1次倾倒：switch_v+0.40_s-1、seed291507、replicate5，在总2.92秒（输入开始0.92秒）倾角跨45°，该次全程峰值66.3°。发生在首次满前推+满右转，尚未换向/回中，不能归因于模式切换；该输入仍是原有滑行分支。该样本后续自动重置数据全部排除。
5. 剩余255条动态序列中，2秒回中转向35条不足10°；3秒死区跨越40条不足10°，其中1条净反向超过5°。极小负角不计明显反向。说明静止起步原地参数的成功不能推广到滑行切入的历史状态。
6. 源码确定存在目标变化率不连续：满左右杆时前后刚出死区从0.9跳到0.5rad/s；半左右杆从0.9跳到0.25。死区跨越测试能复现弱响应，但没有同初态替代控制器对照，不能认定它是全部原因。

建议下一步：先处理零/非零推力切换的连续性与滞回，再针对低推力模型弱响应筛选映射；单纯增加滑行转向倍率或平滑参数不保证解决。新映射应同时覆盖从滑行切入原地、低速左右对称和启动倾倒样本。此次仅分析，未继续修改参数。
