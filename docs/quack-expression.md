# 鸭叫表情调整（2026-10-22）

初版已于2026-10-23部署135；用户反馈幅度太小且朝向单一。下面保留初版设计，最新调整见文末。

- 嘴部不再固定30°。按选中音频的总时长线性决定峰值：≤0.25秒为2°，≥2秒为12°，中间插值；闭嘴保持原−5°目标。双叫使用合成后含间隙的总时长，不逐音节分析振幅。
- 模型内鸭叫使用120ms张嘴、末段150ms收嘴包络；非模型的独立鸭叫沿用原单关节发令方式，仅收小开度并按真实声音时长保持。
- Native50原地行走模型（零速度指令）或坐下模型稳定阶段，可叠加颈俯仰最多2°、头俯仰4°、头偏航5°的轻微互动。现有UART owner统一发令，每20ms偏移变化最多0.5°；叫完平滑归零。
- 非零手动头部输入、非零行走指令或演示编排不产生新的表情偏移，已有偏移平滑归零；其他技能清除偏移。音频出错、取消及反馈保护沿用已有逻辑。
- 使用已有有效角度边界，模型基准已在边界外时不额外纠偏。未改变模型权重、PD、EEPROM、身体动作及音色。
- 独立鸭叫不会给已卸力的脖子新增使能；脖子互动只在已有模型控制期间执行。

测试：在backend-rust执行 `cargo test --locked --offline --bin microduck-observer`；覆盖时长/嘴峰值/收嘴、头颈幅度、坐稳条件、手动及行走优先、限位和归零。ARM构建命令：`CARGO_TARGET_AARCH64_UNKNOWN_LINUX_GNU_LINKER=aarch64-linux-gnu-gcc cargo build --locked --offline --release --target aarch64-unknown-linux-gnu --bin microduck-observer -j2`。

只增加少量固定状态和三角函数计算，无新线程、依赖或音频缓存。实际互动观感及模型闭环稳定性仍需现场验证。

验证结果：291项测试通过、1项忽略，ARM release构建通过；UTF-8无BOM及git diff --check通过。未部署、未发实机动作。

## 2026-10-23 幅度和方向修正

用户实机反馈初版幅度偏小、方向重复。新版头俯仰峰值4→12°、偏航5→18°，颈随俯仰半幅2→6°；偏移限速25→60°/s（50Hz每步最大1.2°）。俯仰改为完整往返波形，四组俯仰/偏航正负组合按播放序号轮换，方向在一次播放内固定，避免逐帧随机抖动。

嘴部按音频时长2～12°保持。原坐稳/原地条件、手动/行走/演示优先级、有效限位及无额外使能保持。上述是偏移目标峰值，短音频和限位可能使实际幅度较小；不改变模型权重或增益。新增测试覆盖四方向、平滑后可达幅度、归零和每步限速。实际观感/稳定性仍待用户测试，代理不发动作。
