# 避障探索第一版

2026-10-26：本地实现，未部署、未发实物动作。用户确认 ToF 安装在头上，随头转动。

## 使用流程

在网页选择“避障探索”（仅自主关闭时可改），在联合观测开启 ToF。普通双足站稳后，沿原入口长按自主键 1.5 秒开启。模式选择保存在 calibration 同目录的 autonomy.json，重启后自主仍默认关闭。网页与实体手柄使用同一后端选择。

头部回正观察 → 连续确认空间 → 低速前进 → 障碍停步 → 向左/向右测距 → 回正 → 小角度转身 → 重新观察。两侧堵住、转向失败或连续三次找路未通过时保持站立并提示一次，等待人工接管。人工输入暂停探索；回中并满足原站稳恢复门后，从观察重新开始。停止、急停、卸力按原规则退出。

探索只输出 twist 和头部目标，由已有串口 owner 执行。只接普通 xgoduck Native50 路径，不开放轮滑。模型、增益、限位、标定和已有故障保护不变。看人检测仍提供相机新鲜度，但探索时禁止看人扫视/自动招呼及鸭叫头部表情与测距姿态竞争。官方跌倒恢复和旧自主起身路径均清掉探索进度，恢复后重新观察。

## 初始参数与边界

- 直行目标 0.2 m/s，与普通档摇杆满杆一致；700mm 以上可开始，前进中不随距离缩小速度输入，450mm 以内撤销直行。它是模型速度指令，不是实测行走速度；零指令也不是机械瞬停保证。
- 左右观察为相对 HOME 偏航 ±25°、俯仰回 HOME，沿原 36°/s 头部限速与有效限位。必须实测头角误差 <3°、头关节速度 <0.15rad/s、机身角速度各轴 <0.2rad/s、倾角 <15°、身体指令近零，持续 350ms 后再累计三个不同 ToF 帧，取最近距离。
- 每帧全部64格必须 status=5 且距离40–4000mm；未知、弱目标、近场、缺格均不能授权移动。当前策略保守，斜地面/边缘无回波可能让它等待，实测后再决定区域筛选，不能直接把无回波当空地。
- ToF 按采集时间计龄，最多200ms；相机有效推理结果最多600ms。旧 helper 没有 captureClockVerified 可继续用于显示，但不能授权探索，需要与后端一并更新。
- 小步转向目标20°、指令±1rad/s（普通摇杆满杆转向），利用现有IMU yaw测量，最多3秒；偏离35°、正前方小于250mm、传感器失效时撤销运动。回正后才能转身，无自动倒退。障碍停止/传感器失效清掉速度平滑尾值。
- 每个停步/观察阶段最多6秒；找路连续三次未通过则等待，连续前进3秒才重置尝试次数。
- 机身转动的扫掠空间、ToF/头/IMU方向一致性、刹停距离和人体动态避让没有实机验收。仅平坦无落差场地；不具备台阶/悬崖检测、地图定位或全身碰撞感知。
