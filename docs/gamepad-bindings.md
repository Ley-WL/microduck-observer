## 自定义动作（2026-10-22）

模型管理点击「＋ 新增动作」，填写动作名称/ID、模型名称、ONNX及配置来源。新动作使用独立的`custom-` ID，不替换原有动作。当前可选择舞蹈、拾取、翻滚、左右踢球的兼容执行模板；其观测、关节顺序、命令及结束条件必须与训练一致，不支持任意网络或未适配任务。官方manifest仍按已有适配范围校验。

创建与首个模型验证为同一事务，失败不留下空动作。成功后手柄设置下拉框自动提供该动作（已打开页面可点重新读取），保存后网页和实体手柄共用映射，重启保留。先站立并回中后触发，按下仅执行一次；急停与停止保持不受影响。动作及权重在运动启动前预加载，切换不在串口循环加载文件。最多16个自定义动作；后续可继续导入候选、应用或回滚，无删除/任意重命名接口。

新增动作默认选用首个验证通过的模型，但不会启动运动。新配置只能在控制停止后保存；实机动作仍需另行验收。

# 手柄自定义控制

2026-10-21：本地实现，未部署实机。

侧栏「手柄设置」编辑 A、X、Y、LB、RB、十字键上/左/右，保存到主板配置；网页虚拟手柄和板端 Linux evdev 手柄共用映射。可选不绑定、站立、坐下、倒地起身、演示、拾取、翻滚、左右踢球、舞蹈、抬脚/落脚、嘎一下。动作调用已有执行入口，使用「模型管理」当前选择的权重。

## 使用与生效

停止模型及其他控制任务，进入手柄设置，选择动作后保存。恢复默认先写入草稿，点击保存才生效。页面显示实体按键高亮，但不提供动作试运行。

配置在 `MICRODUCK_CALIBRATION_FILE` 同目录的 `gamepad-bindings.json`，包含 schemaVersion、revision 和 bindings；临时文件写入、同步后原子替换，保存失败保持旧内存配置。设备重启重新加载；无文件使用当前 Observer 默认映射。损坏或非法配置启动时报错，不静默套用不同映射。

实体输入循环读取配置版本，变更后释放旧控制状态并要求全部松键和回中。网页姿态页挂载时读取，并每2秒同步；标签、可用状态、动作分发共用同一映射。配置未读取或读取失败时自定义按钮禁用。修改带 revision，旧版本保存被拒绝。保存与模型/运动任务共用互斥门，运行期间拒绝。

倒地起身改绑到任何键仍需长按：实体沿用14个40ms采样计数，网页560ms。长按只触发一次，松开、失焦、配置/可用状态改变、组件卸载会取消网页计时。连接时一直按住的键、配置变更时的旧按键状态均不会触发新动作。不绑定的键不会引发控制权接管或人工打断自主。

## 固定控制

Back/Select急停卸力，B停止保持，Start实体长按2秒确认卸力并关机（网页预留），LT加速，RT叫声及实体双击/长按语义，十字键下长按1.5秒自主，双摇杆功能保持。实体调试模式仍只显示输入、不分发控制。

模型可用性、控制权、姿态就绪、反馈超时及现有舵机保护仍由原执行链路决定；映射保存不会运行模型。多个键可绑定同一动作；单次采样最多分发一个动作，急停和停止优先。

## 与官方对照

官方将物理和网络手柄映射集中在 `pad-map`，`robotctl pad bind/reset` 修改 `[pad]`，约1秒重新加载；官方开放 a/b/x/y/lb/rb 六个技能键，Start、Select、十字键及触发器固定。其配置还包含摇杆轴、死区和头部等参数。

本次采用“集中映射、持久化、恢复默认、固定安全控制”的方式，保留 Observer 已有默认操作。与官方不同，B在这里是停止键所以固定，同时开放上/左/右三个已有技能键；本次不提供摇杆轴、死区、速度上限或手柄IMU配置，也不解析官方TOML。

来源：[官方 pad-map](https://github.com/pollen-robotics/microduck/tree/main/pad-map)、[官方配置热加载](https://github.com/pollen-robotics/microduck/blob/main/pad-map/src/bindings.rs)、[官方手册](https://github.com/pollen-robotics/microduck/blob/main/docs/robot/cheatsheet.md)。

## API 与验证

GET `/api/v1/gamepad/bindings` 返回 config/defaults/buttons/actions；POST 同一路径传 `{revision, bindings}` 全部8个可配置键。非法动作、固定键、缺失键、旧revision拒绝，所有动作仍通过已有运动接口。

自动化覆盖默认行为回归、新动作映射、按住不重发、配置变化回中、起身长按、诊断模式、固定停止优先、未绑定键不接管、持久化失败、重启保留及恢复默认。接口集成测试沿用 `tests/test_model_registry_api.py` 的隔离模拟环境。实物按键与动作尚待部署后验证。

本次本地验证：Rust 275项通过、1项外部fixture忽略；前端84项通过，Rust debug与网页生产构建通过。3组隔离API集成测试通过，浏览器实际保存X→左脚踢球、返回姿态页确认标签同步并恢复默认成功。未构建ARM发布包、未部署或执行实物动作。
