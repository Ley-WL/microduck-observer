# 轮滑摇杆转向优化（2026-10-29）

已接入本地源码，未部署。最终方案为低推力转向优先、连续混合目标航向速率、推力渐变，以及检测转向停滞后的短时撤推力重试。冻结模型权重不变，普通行走分支不变。

最终两轮名义仿真合计6784次未触发倾倒门；其中6272次10秒斜推长按均沿指令方向转动且转角≥15.6°。动态回中前2秒仍有7/512次转角不足10°，但后续3秒全部恢复明显转向；不宣称精确跟随、所有瞬态均稳定或实机已验证。

## 实际操作变化

- 不带左右转向时，保留原前后目标输入；零到满推力指令约0.5秒，前后反向按同一斜率过渡。松前后杆/过期输入立即清零推力。
- 左右转向有效时，前后输入绝对值≤0.15优先原地转向；0.15～0.4经过smoothstep逐渐映射到0～0.4。示例原输入0.2/0.25/0.3/0.35/0.4约映射为0.0416/0.1408/0.2592/0.3584/0.4。这里是模型推力指令，不是实测米/秒。
- 实际输出推力≤0.2时，有效左右杆采用±0.9rad/s目标航向速率；0.2～0.4连续混合到原有左右输入×2，满推力时仍保留比例转向（满左右杆±0.5rad/s）。没有旧版“前后从0变成非0就立即切档”的分界。
- 航向误差≥0.4rad且实测yaw变化率<0.08rad/s，连续0.5秒时触发补救：撤掉前后推力，以当前朝向重设目标，约0.2秒稳定后尝试约1秒原地转向，再恢复用户输入。仍受±0.5rad模型误差上限约束。
- 松转向杆、输入过期或左右换向立即取消补救；模式退出沿用原控制器重置。所有计时按最多50ms单周期累计，暂停不会跳过控制阶段。
- 新诊断字段：rollerHeading.modelDriveCommand、rollerHeading.turnAssistRemainingSeconds。

这改变了小幅斜推的手感：优先转身，较大前后幅度才滑行；低推力时小左右杆不再代表很慢的转速，转角更多由按住时长控制。保留原模型的局限：不同初态仍有转速差异，回中后可能短暂停顿再重试，松杆后也仍存在实体惯性。
