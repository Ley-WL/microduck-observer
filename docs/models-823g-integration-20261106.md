网页手柄新增“双脚蹲起”独立蹲下 / 站起按钮，模型管理新增 crouch 槽位。下蹲指令 twist.vx=1，站起=0，下蹲维持至用户请求站起；下蹲后即可请求站起，不设固定等待。保持与轮滑蹲滑和坐姿模型独立，跨模型误选站起会被拒绝，站起确认稳定500ms才交给行走，10秒超时卸力。下蹲期间不覆盖模型头部目标。

新跌倒起身和双脚蹲起采用 HOME + raw action、scale1、无输出 EMA、无电压幅度缩放、无关节速度/陀螺仪低通。延用原生50Hz读取和硬件速度单样本延迟。新翻滚也使用原始模型输出，改用完整旋转与直立稳定的退出检测，5秒未完成卸力；不套旧官方1.5秒截断和行走滤波。旧翻滚模型合同仍可回退使用。

行走沿用本次仿真使用的0.9幅度、腿部新值0.7、头部新值1.0，现有电压补偿逻辑保持。坐下站起保留官方无EMA合同。拾取保留原有2.8秒阶段窗口和嘴部编排。实体舵机增益沿用设备配置，不把训练器参数写进设备。

部署使用 tools/deploy-runtime.py --approved-823g-models --preserve-device-settings；执行前验证模型哈希、原生模型库加载/推理、候选服务只读硬件采样，切换后再次核对API选择和哈希。已有标定、增益、身份和旧模型保持；设备存在持久化不同选择时会拒绝本次部署而不是静默覆盖。

本轮部署仅做只读验证，不代表新模型的实机动作验收。跌倒起身仿真虽然128/128曾达到交接条件，末段颈部HOME偏差较旧版增大，详见训练归档。
